# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Anyone who wants to preview how a website link looks when shared on social media, check its Open Graph metadata, and create beautiful link previews.

## Product Purpose
A small, beautifully made utility for the web. Paste a URL, fetch the metadata, see the social preview, and export it as an image if desired.

## Positioning
A minimalistic, single-purpose editorial utility rather than a complex dashboard or multi-tool.

## Operating Context
Used in browsers as a quick workflow step before publishing links on social media or in messaging apps.

## Capabilities and Constraints
- Fetches Open Graph metadata from URLs securely.
- Exports the visual preview as an image.
- Graceful fallbacks for missing metadata or fetch errors.

## Brand Commitments
No strict brand commitments yet; keep it neutral but polished. 

## Evidence on Hand
- `design.md` specifies a minimal, editorial design language (warm ivory backgrounds, near-black typography).
- Active frontend and backend codebases exist.

## Product Principles
1. **Do one thing exceptionally well.** The URL input is the primary interaction.
2. **Minimal and Editorial.** The interface should recede and not look like a complex dashboard.
3. **Content leads.** The fetched image provides the color; the UI remains quiet.

## Accessibility & Inclusion
Standard web accessibility (WCAG AA) with full keyboard support.
